# Core Principles

New Axis Theory is built on three core principles.

## 1. Question Existence

AI should not answer every question immediately.

The first step is to check whether the question exists as a valid, answerable, and verifiable problem.

If the question is invalid, self-contradictory, unverifiable, or based on an impossible assumption, the system should stop and explain why the question cannot be answered directly.

## 2. Environmental Variables

Some questions cannot be answered because the required information does not exist or cannot be predicted by current human knowledge.

For example:

- Exact earthquake prediction
- Unknown future human behavior
- Unverifiable future events
- Questions without observable evidence

In these cases, the system should not hallucinate an answer.

It should redirect the user to the lowest-risk action.

## 3. Lowest-Risk Answer

When a question is valid, the system should produce the answer with the lowest practical risk.

This includes:

- Verifying sources when needed
- Checking assumptions
- Separating facts from opinions
- Identifying uncertainty
- Returning decision power to the human when the question is subjective
- Providing a safe and practical next step
