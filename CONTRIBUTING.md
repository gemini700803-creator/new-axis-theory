# Contributing

Thank you for your interest in New Axis Theory.

This project is an open reasoning framework focused on question validity, environmental variables, verification, and lowest-risk AI answers.

## How to contribute

You can contribute by:

- Suggesting new benchmark questions
- Improving test case descriptions
- Adding examples of invalid or unverifiable questions
- Improving documentation clarity
- Proposing evaluation criteria

## Benchmark contribution format

Please use this format when suggesting a new test case:

### Test Case Title

Question:

Expected behavior:

Failure behavior:

Category:

## Project focus

This project is not focused on building a larger AI model.

It focuses on building a reasoning control layer that helps AI systems decide whether a question should be answered, verified, reframed, or blocked.

## Code of conduct

Please keep discussions respectful, clear, and focused on improving reliability and risk-aware AI reasoning.
