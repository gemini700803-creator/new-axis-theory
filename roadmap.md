# Roadmap

This roadmap describes the planned development path of New Axis Theory.

The goal is to transform the theory from a written reasoning framework into a testable AI control layer.

## Phase 1: Concept Structure

Status: In progress

Goals:

- Define core principles
- Define the Question Gate
- Define the Environmental Variable Engine
- Define the Subjective Objective Router
- Define the Verification and Trust layer
- Define the Answer Release Gate
- Create early test cases

## Phase 2: Rule Extraction

Status: Planned

Goals:

- Convert written principles into structured rules
- Create machine-readable rule files
- Define rule IDs
- Define trigger conditions
- Define failure conditions
- Define routing logic

## Phase 3: Test Dataset

Status: Planned

Goals:

- Build 100 golden test cases
- Expand to 1,000 environmental variable test cases
- Compare responses from different AI models
- Measure hallucination, forced-answer behavior, invalid-question detection, and risk-aware output quality

## Phase 4: Prototype Engine

Status: Planned

Goals:

- Build a simple command-line prototype
- Add question classification
- Add verification state
- Add environmental variable detection
- Add answer release gate
- Connect to an LLM API

## Phase 5: Public Demonstration

Status: Planned

Goals:

- Publish benchmark results
- Show example comparisons
- Build a lightweight web demo
- Allow users to test how New Axis Theory handles risky, invalid, subjective, and unverifiable questions
